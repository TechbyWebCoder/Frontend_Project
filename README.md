A curated collection of **frontend mini-projects** built using **HTML, CSS, and JavaScript**. This repository is designed to help beginners and intermediate learners strengthen their frontend development skills through **hands-on practice**.

## 📌 About the Repository

This project contains multiple small-to-medium frontend applications such as calculators, converters, games, UI components, and utility tools. Each project focuses on improving a specific concept like:

* DOM Manipulation
* JavaScript Logic Building
* UI/UX Design with CSS
* Event Handling
* Responsive Design

## 🛠️ Technologies Used

### Core Technologies

* **HTML5** – Structure and semantic markup for web pages
* **CSS3** – Styling, layouts, animations, and responsive design
* **JavaScript (ES6+)** – Logic, DOM manipulation, events, and interactivity

### Tools & Platforms

* **GitHub** – Version control and project hosting
* **GitHub Pages** – Hosting live demos for projects
* **Netlify** – Deployment and hosting of frontend applications
* **VS Code** – Code editor for development

### Concepts Covered

* DOM Manipulation
* Event Handling
* Responsive Web Design
* UI/UX Design Principles
* JavaScript Logic Building

## ▶️ How to Use

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/frontend-project.git
   ```
2. Open any project folder.
3. Run the project by opening the `index.html` file in your browser.
